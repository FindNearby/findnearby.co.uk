FIND NEARBY WEBSITE STARTER

This folder is a simple static website starter.

FILES
- index.html = homepage
- features.html = features page
- accessibility.html = accessibility page
- coverage.html = fast UK and Ireland counts page
- pro.html = Pro page
- faq.html = FAQ page
- privacy.html = placeholder privacy page
- terms.html = placeholder terms page
- css/styles.css = all styling
- images/ = put screenshots and logo files here later

HOW TO PREVIEW LOCALLY
1. Open the folder in VS Code.
2. In Finder, open index.html in your browser.
3. Or right-click index.html and choose your browser.
4. When you edit and save a file, refresh the browser tab.

WHAT TO CUSTOMISE FIRST
1. Add your real logo in the header if you want.
2. Replace the homepage screenshot placeholder with real screenshots.
3. Paste your real privacy policy into privacy.html.
4. Paste your real terms into terms.html if needed.
5. When you are happy, upload the whole folder to Netlify.

IMPORTANT
If you deploy manually on Netlify, drag the FOLDER that contains index.html.
Do not drag a zip file.
