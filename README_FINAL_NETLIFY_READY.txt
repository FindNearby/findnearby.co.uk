Important:
Upload the folder that contains index.html directly. Do not upload a parent folder that contains this folder inside it.

Manual update workflow:
1. Keep a dated backup zip before changing anything.
2. Edit files in VS Code.
3. Open index.html locally for a quick visual check.
4. For redirects and clean URLs, test on Netlify because _redirects does not run from a local file browser preview.
5. After every important website change, update this folder, create a fresh zip, and keep the old zip for rollback.
