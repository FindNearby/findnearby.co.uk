Community, charities and map updates

Find Nearby helps with lots of everyday searches, including toilets, parking, benches, playparks, health locations and more. Key accessibility, family and health searches are free with no ads, and the app uses public map data that can improve over time.

For charities and community groups

Find Nearby may be useful for accessibility groups, carers, parent groups, local community groups, travel groups and public health or wellbeing projects.

The app is not only for people with access needs or parents. It also helps anyone find toilets, parking, benches, playparks, drinking water, chemists, cash machines, bus stops, post boxes, recycling centres and more.

For journalists and newsletters

Find Nearby is built in Glasgow by Find Nearby Ltd. It helps people find practical nearby places, with 1.16 million+ locations mapped across the UK and Ireland plus worldwide search support where public map data is available.

Key searches for accessible toilets, accessible parking, baby-changing toilets, parent & child parking, hospitals, GPs and defibrillators are free with no ads.

Help improve public map data

Find Nearby uses public map data, including OpenStreetMap. If a toilet, parking space, bench, playpark, shop, public service or other place is missing, closed, in the wrong position or missing useful details, improving OpenStreetMap can help Find Nearby and other map users too.

Edit OpenStreetMap directly

Create a free OpenStreetMap account if you know the correct details and are comfortable updating the map yourself.

This works best for clear, factual information such as the exact position, name, opening hours, wheelchair access, toilet details, parking restrictions or whether a place has closed.

Good edits should be based on local knowledge or reliable evidence and should help the wider public map community, not only one app.

Leave an OpenStreetMap Note

If you are not ready to edit the map yourself, OpenStreetMap Notes let you report a possible map issue for volunteer mappers to review.

Notes are useful when you can explain what is wrong but would rather someone else checks and updates the map.

Include clear details such as what is missing or incorrect, the exact location, whether the place has closed, and any useful context that would help a mapper verify it.

Why updates may not appear instantly

Find Nearby uses a fast UK and Ireland search database, so public map changes may take time to appear inside the app. Opening hours, access rules, toilet details, parking restrictions and accessibility information can also change, so always check critical information before relying on it.

Share Find Nearby with your community

If Find Nearby would be useful to your audience, you are welcome to share the website or app store links. Feedback from real users is especially helpful for improving the app responsibly.
